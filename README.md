# ⚡ ALX Project 0x00: Next.js Setup

The first Next.js project in the **ALX ProDev Frontend** programme: setting up Next.js with TypeScript and Tailwind, pages routing, and reusable components.

## What's inside [`alx-project-0x00/`](alx-project-0x00/)

- Pages router: `index`, `about` and `landing` pages
- Reusable `Button`, `Card` and `Pill` components with typed props (`interfaces/`)
- Styling with Tailwind CSS v4

## Run it

```bash
git clone https://github.com/Dwaynemaster007/alx-project-0x00-setup.git
cd alx-project-0x00-setup/alx-project-0x00
npm install
npm run dev
```
